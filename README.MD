# Flask Web Application

## Overview
This project is a web application built with Python and Flask. It provides a simple interface for accessing the application's main functionality.

## Requirements
- Python 3
- Flask

## Setup and Installation

1. Clone or download the repository.
2. Open a terminal in the project folder.
3. Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

4. Install Flask:

```bash
pip install flask
```

## Running the Application

Run the application using:

```bash
python app.py
```

Open the local URL displayed in the terminal in your browser.

## Project Structure

- `app.py` — Main Flask application.
- `templates/` — HTML templates used by the application.
- `AI_LOG.md` — Documents AI assistance during development.
